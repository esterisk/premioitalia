## About Premio Italia

This is the source code of the Premio Italia voting site.

Premio Italia is the national award of the science ficton and fantasy field.
Voting is open to whoever attended an Italian national convention (Italcon) or a selected number of other affiliated conventions.
The vote is structured in three phases:

1. proposing electable candidates - open to everyone. Every candidate will be included in a long list of proposals in the second phase.
2. selecting the nominees - open to registered voters. The voters can propose or select from the long list up to three candidates (per category). The number of votes will determine the short list of nominees.
3. electing the winners - open to registered voters. The voters choose from the nominees up to three ordered preferences. Through a balloting system based on australian ballot the winners are elected.

This code is published with the purpose of transparency. It can be forked and used by anyone interested in building a voting site for similar awards.
